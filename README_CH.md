# 代码上下文打包工具 (记忆配置版)
[切换到英文版本](README.md)

## 简介
这是一个用于快速打包代码上下文的工具，支持自定义过滤规则和输出目录。通过简单的拖放操作或手动选择文件夹，您可以轻松生成包含代码内容的文本文件，方便用于代码分析或上下文共享。

## 功能
- **拖放文件夹**：支持将文件夹拖入界面进行快速选择。
- **自定义过滤规则**：可忽略特定文件夹、文件后缀和文件名。
- **记忆配置**：自动保存用户的过滤规则和输出目录。
- **输出目录设置**：支持自定义输出文件保存路径。
- **高级选项**：可展开高级面板，编辑过滤规则。

## 使用方法
1. 打开程序。
2. 将目标文件夹拖入界面，或点击“手动选择输入文件夹”按钮。
3. （可选）点击“更改”按钮设置输出目录。
4. （可选）展开高级选项，编辑过滤规则。
5. 点击“立即打包代码”按钮，生成打包文件。

## 配置文件
程序会自动生成 `bundler_config.json` 文件，保存用户的过滤规则和输出目录。
