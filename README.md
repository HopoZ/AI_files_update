# Code Context Bundler (Config Memory Version)
[Switch to Chinese version](README_CH.md)

## Introduction
This is a tool for quickly bundling code context, supporting custom filtering rules and output directories. With simple drag-and-drop operations or manual folder selection, you can easily generate text files containing code content for analysis or context sharing.

## Features
- **Drag-and-Drop Folder**: Quickly select folders by dragging them into the interface.
- **Custom Filtering Rules**: Ignore specific folders, file extensions, and filenames.
- **Config Memory**: Automatically saves user filtering rules and output directory.
- **Output Directory Setting**: Customize the output file save path.
- **Advanced Options**: Expand the advanced panel to edit filtering rules.

## Usage
1. Open the program.
2. Drag the target folder into the interface or click the "Manually Select Input Folder" button.
3. (Optional) Click the "Change" button to set the output directory.
4. (Optional) Expand advanced options to edit filtering rules.
5. Click the "Run Bundler" button to generate the bundled file.

## Configuration File
The program automatically generates a `bundler_config.json` file to save user filtering rules and output directory.
